# The Good Garden — Agent Start Here

## Mission
Build a calm, beautiful Christian Montessori-inspired learning adventure in Godot 4. The child experiences a living storybook world; the curriculum operates underneath the game rather than presenting itself as school software.

## Current Build Goal
Do NOT build the full curriculum. Build the vertical slice: Home, Garden, a Village path, Chapel/Atrium, Miriam, one gardening activity, one practical-life activity, one Scripture presentation, Journal/Invitation flow, and persistent world changes.

## Non-negotiables
- Godot 4.x, GDScript, stylized 3D.
- Elevated three-quarter third-person exploration with controlled camera.
- Touch + mouse/gamepad-friendly interaction architecture.
- Data-driven content; avoid hard-coding individual lessons into core systems.
- CC0-first asset strategy. Existing Quaternius assets are available; KayKit and Kenney are preferred complements. Track every third-party asset.
- No combat, loot loops, streak manipulation, energy systems, battle passes, or reward explosions.
- Faith is not currency. Prayer and Scripture are not scored.
- Concrete experience before abstract explanation.
- The world should visibly remember the child's work.
- Keep code modular, typed where useful, documented, testable, and human-readable.

## Prototype Success Question
Does this loop feel compelling to a child: explore -> notice/discover a need -> perform a tactile activity -> see a meaningful world change -> freely continue exploring?
