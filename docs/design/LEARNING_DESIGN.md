# Learning Design

## Montessori-Inspired Principles
The project is inspired by Montessori concepts but should not claim official Montessori accreditation without appropriate review/authorization.

- prepared environment
- independence and choice within limits
- hands-on concrete materials
- concrete-to-abstract progression
- repetition by choice
- purposeful practical life
- self-correction where possible
- observation of the learner
- uninterrupted free-work opportunities
- adult/guide as facilitator rather than constant lecturer

## Subject Integration
Avoid subject-select menus in the child's primary experience. Learning is embedded in place and purpose.

Garden: biology, counting, patterns, seasons, stewardship.
Kitchen: fractions, measurement, sequencing, reading, hospitality.
Workshop: geometry, measurement, plans, construction, diligence.
Market: arithmetic, money, comparison, reading, honesty/fairness.
Forest: science, classification, observation, creation.
Village: language, social reasoning, service, communication.

## Reusable Activity Systems
Target 12–15 robust systems before scaling content. One mechanic should support many contexts; e.g. measuring boards, garden rows, fabric, ingredients, plant growth, and map distances.

## Real-World Invitations
Optional prompts can ask the child to measure household objects, help set a table, care for a plant/animal, observe leaves/insects, organize a space, create something, read with an adult, or quietly help someone. Never punish non-completion.
