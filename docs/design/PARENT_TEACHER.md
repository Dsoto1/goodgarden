# Parent / Teacher Experience

## Goal
Provide useful observations without turning the child experience into constant testing.

## Potential Controls
- age/readiness range
- reading support level
- math readiness/progression
- session length guidance (e.g. 15/30/45 min)
- optional real-world invitations
- content/theological settings only where thoughtfully supported

## Observation Examples
- independently completed four grouping activities
- revisited measuring work three times
- requested reading assistance twice
- spent time retelling a Scripture presentation
- returned voluntarily to gardening work

Avoid reducing the experience to only percentages. Never infer faith, virtue, obedience, or spiritual maturity from telemetry.

## Privacy
Collect the minimum child data required. Prefer local/offline profiles for the first product. Any future cloud or classroom features require a dedicated child-privacy/legal review.
