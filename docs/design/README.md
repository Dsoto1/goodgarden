# The Good Garden — Pre-Production Starter Package

This package captures the current game vision and provides an AI/developer handoff for a Godot 4 vertical slice.

Start with `AGENT_START_HERE.md`.

The project is intentionally scoped in two layers:
- **Now:** prove the vertical slice.
- **Later:** scale the proven systems into a 12-week / 60-day first season and wider world.

The documents are design direction, not a claim of Montessori certification or theological approval. Curriculum, child-development, privacy/legal, and Scripture content should receive qualified human review before commercial release.
